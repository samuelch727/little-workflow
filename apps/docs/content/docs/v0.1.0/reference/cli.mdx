---
title: CLI
description: Planned command-line surface for validation, runs, replay, artifacts, skills, plugins, and approvals.
---

The CLI should support the same developer loop as the SDK.

## Validate And Run

```bash
little validate workflow.json
little validate pipeline.json
little orchestrate request.json
little run workflow.json --input input.json
little run pipeline.json --input input.json
```

## Inspect Runs

```bash
little runs list
little runs inspect run_123
little runs stream run_123
little runs timeline run_123
little steps inspect run_123 review-candidates.extract-profile
little replay run_123
little retry run_123 --from review-candidates.extract-profile
little fork run_123 --patch patch.json
```

## Artifacts, Skills, Plugins, Approvals

```bash
little artifacts list run_123
little artifacts get art_123
little skills list
little skills inspect acme.hr-workflows/candidate-review
little plugins list
little plugins inspect @acme/lw-hr
little approvals list
little approvals approve apv_123 --file decision.json
```

The first alpha CLI should be narrower: `validate`, `orchestrate`, `run`, `events`, and `replay`.
