---
title: Capability Firewall
description: The planner can only reference tools the developer passed in. The runtime can only invoke tools recorded in the compiled workflow.
---

The capability firewall is a runtime rule, not a prompt instruction. It exists so that AI-generated workflows cannot grant themselves new powers.

## The Rule

A tool is callable from a workflow if and only if the developer passed it into the workflow definition — either on `model().tools` (planner-time) or in `globalTools` (workflow-time). The planner cannot invent tool references the developer did not provide.

```ts
createLittleWorkflow({
  planner: model(openai('gpt-5'), {
    tools: {
      bash: createBashTool(), // planner can use this during planning
    },
  }),
  globalTools: {
    parsePdf: parsePdfTool, // planner can include this in compiled steps
  },
});
```

The planner sees the tool's description and input schema and decides whether and how to call it. There is no separate `plannerVisible` / `workflowCallable` flag. The scope is the map the tool lives in.

## Snapshotting

Every WorkflowVersion records the capability surface it was compiled against:

- the name and scope (`model().tools` vs `globalTools`) of each referenced tool
- the tool's description and input schema, hashed
- for plugin-provided tools, the plugin manifest hash and version
- for provider-executed tools, the provider name and the provider tool identifier

At execution time the worker re-reads the live tool descriptor and compares it against the snapshot. A mismatch is `capability_drift` and either fails the step or pauses the run for review, depending on policy.

This is what stops an MCP server or third-party plugin from quietly changing a tool's behavior between compile and execution.

## Skills Are Separate

Skills are context, not authority. A skill may suggest tools, describe a process, or include scripts as inert files. None of that grants runtime power. A step still needs a tool reference from `model().tools` or `globalTools` before any code runs.
