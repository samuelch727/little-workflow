`v1.0.0` is the planned production-ready Little Harness control plane.

Expected focus:

- production-grade session isolation
- durable trace and artifact backends
- tenant-aware Persistent Dirs
- policy controls for tools, network, and exports
- operational observability for many parallel sessions
- compatibility with Little Workflow without requiring it
