`v0.2.0` is where the runtime stops being a single-team tool and becomes something a community can extend. It adds the fan-out and reducer story for high-throughput workflows, the plugin packaging surface for third-party adapters and UI panels, and the module/registry story for sharing.

## What This Version Includes

Everything in [v0.1.0](/docs/v0.1.0), plus:

- sharded fan-out and tree reducers for high-throughput foreach
- expanded dashboard views for fan-out, pipelines, cost, replay, and fork
- storage, queue, sandbox, and telemetry adapter packaging
- custom step type plugins
- third-party UI inspector panels
- remote and private SkillPack and plugin registry support
- workflow modules as packageable units
- marketplace-oriented package distribution flows

## What This Version Does Not Include

Visual workflow editing, multi-tenant organization controls, worker autoscaling, enterprise audit exports, evidence graphs, and evaluation suites arrive in [v1.0.0](/docs/v1.0.0). See [Changelog](/docs/v0.2.0/reference/changelog).
