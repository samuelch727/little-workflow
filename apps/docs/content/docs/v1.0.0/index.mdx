`v1.0.0` is the enterprise-ready milestone: visual editing, multi-tenant organization controls, autoscaling, audit exports, and the evidence graph that finally lets a workflow's output be traced back to every source span that informed it.

## What This Version Includes

Everything in [v0.2.0](/docs/v0.2.0), plus:

- visual workflow editing and built-in planner templates
- workflow optimization suggestions
- multi-tenant organization controls
- worker autoscaling
- enterprise audit and compliance exports
- evidence graph and evaluation suite support
- multiple durable execution backends behind the same runtime contract
- marketplace-quality plugin install, update, migration, and provenance flows

## Why This Is Enterprise-Ready

Earlier versions ship the runtime, durability, and ecosystem. `v1.0.0` adds the organizational and compliance machinery a real team needs to put generated workflows in front of auditors, regulators, and customers.
