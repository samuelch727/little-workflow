# Repository Instructions

1. Use `pnpm` as the preferred package manager.
2. Keep repo-root `./skills/` package skills aligned with agent-facing package behavior and docs. When Little Harness or Little Workflow skill behavior changes, check whether `skills/little-harness/SKILL.md` and `skills/little-workflow/SKILL.md` need matching updates.
3. Consult the published docs under `apps/docs` and `apps/little-harness-doc` for current terminology and behavior, and keep them up to date.
