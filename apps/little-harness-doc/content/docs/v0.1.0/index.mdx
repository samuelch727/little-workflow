`v0.1.0` is the planned first stable Little Harness release for local and self-hosted apps.

Expected focus:

- stable `createHarness` and `streamHarness` API
- stable session continuation contract
- stable Persistent Dir commits
- reliable artifact exports
- documented local runtime limits
- migration guidance from alpha and beta
