These docs cover the Little Harness alpha line — `0.2.0-alpha.3` in this release as `@little-stack/harness`. The URL path keeps the historical `v0.1.0-alpha` segment so old links stay stable; it is not the package version. Little Harness is a local-first agent runtime where the developer provides a host, model, system prompt, tools, skills, and optional Persistent Dirs. It requires Node.js 22+ and AI SDK 7 (`ai` is a peer dependency).

## What This Version Proves

- Auto-created sessions with isolated workspaces.
- Message file staging for raw AI SDK chat input.
- Tools that can return large artifact-backed outputs instead of flooding model context.
- Skills exposed read-only and disclosed progressively.
- Opt-in harness memory for model-authored durable lessons.
- Local Host with `.little-harness` session folders, traces, and artifacts.
- Persistent Dirs with `harnessDir` plus developer-owned source logic.
- After-turn commits for Persistent Dirs.
- No parallel turns inside one session; same-session calls queue by default.
- Persistence errors surfaced to the host app and trace, not injected into normal agent context.
- A local runtime path powered by just-bash, run in a subprocess sandbox by default for any turn that can execute code or reach the network.
- Opt-in execution tiers that escalate commands just-bash cannot run to an environment you provide.
- Little Workflow workflows exposed as typed tools, with per-session fan-out budgets.
- Chat SDK and web-rich connectors, with inbound file attachments and reactions captured as run outcomes.
- Outcome capture (`outcome.reported`) and success rates per prompt from the CLI.
