The Little Workflow integration for LittleDB, the private client's tracing
World (`db.tracingWorld()`), is documented in one place:
[LittleDB with Little Workflow](/docs/littledb/workflow). Experiments and the
eval worker are in [Experiments](/docs/littledb/experiments).

LittleDB is private source and not installable. Little Workflow works without it;
the default is [Local World](/docs/workflow/v0.1.0-alpha/running/local-world).
See [LittleDB](/docs/littledb) for status.
