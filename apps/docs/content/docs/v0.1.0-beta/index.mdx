title: v0.1.0-beta
description: Polished developer SDK and governance on top of the alpha local runtime.
---

`v0.1.0-beta` makes the local runtime usable as a developer SDK without adding distributed production complexity. Everything still runs locally; what changes is the surface the developer authors against and the policy machinery enforcing it.

## What This Version Includes

Everything in [v0.1.0-alpha](/docs/v0.1.0-alpha), plus:

- polished `createLittleWorkflow()`, `runWorkflow()`, and `createRuntime()` APIs
- `chainWorkflows()` with explicit developer-authored `transform()` for schema bridging
- raw local `SKILL.md` support and SkillPack manifest validation
- manifest-first plugin packages for local model, tool, skill, policy, adapter, module, and UI contributions
- governed `model()` wrappers with role, capabilities, quality tier, cost class, allowed overrides, and limits
- capability firewall rules: planner-visible vs. workflow-callable
- content-addressed local blobs
- typed evidence references
- budget reservation, human approval gates
- basic OpenTelemetry spans for orchestration, planning, and step execution
- a minimal run inspector

## What This Version Does Not Include

Production durability (Postgres, Redis, S3, lease fencing), sharded fan-out, tree reducers, custom step types, and visual editing arrive in later versions. See [Changelog](/docs/v0.1.0-beta/reference/changelog).
