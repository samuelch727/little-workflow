---
title: What Little Harness Is
description: A proposed zero-config managed agent runtime for tools, skills, files, traces, and isolated sessions.
---

Little Harness is a proposed managed runtime for apps that need agents to use tools, skills, files, and scripts without making the developer design the sandbox, storage, artifact, or tracing layer first.

The developer-facing contract should stay small: provide instructions, tools, optional skills, and optional Persistent Dirs. Little Harness creates the session workspace, isolates it from other sessions, stores large outputs as artifacts, records a trace, and returns a result.

```txt
app request
-> Little Harness session
-> isolated workspace + skills + tools + artifacts
-> optional Persistent Dirs
-> assistant result + trace + persistence status
```

## Product Boundary

Little Harness is:

- a managed agent runtime
- an isolated session workspace
- a tool and skill harness
- an artifact-first file surface
- a trace and persistence boundary
- a first runtime target for just-bash

Little Harness is not:

- a workflow compiler
- a chat UI
- a requirement to adopt Little Workflow
- a reason to expose arbitrary host paths to the model
- a requirement that developers define containers or microVMs before their first agent works
