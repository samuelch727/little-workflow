This section is a guided tour of the alpha SDK internals. The [SDK Implementation Spec](/docs/v0.1.0-alpha/reference/sdk-implementation) lists the contract; these pages walk through how that contract is implemented in the `little-workflow` package — every diagram traces a real path through the source.

If you only need to use the SDK, start with the [Quickstart](/docs/v0.1.0-alpha/quickstart) and [Core Mental Model](/docs/v0.1.0-alpha/mental-model). Read on here if you want to extend, debug, or audit the runtime.

## End-To-End View

The alpha SDK is one package shaped around a single loop: turn a `WorkflowDefinition` into a locked `WorkflowVersion`, execute it against Local World, and persist every result boundary so a kill can be resumed.

The shipped code in `packages/little-workflow/src/` corresponds 1:1 to these stages:

| Stage | Source |
| --- | --- |
| Authoring + types | `authoring.ts`, `schema.ts` |
| Tool registry | `tool-registry.ts` |
| Compile pipeline | `compiler.ts`, `compiler-lock.ts`, `canonical.ts` |
| LWIR validation | `lwir.ts`, `expressions.ts` |
| Workflow harness AI SDK bridge | `packages/little-harness/src/workflow-harness/workflow-harness.ts` |
| Runtime loop | `runtime.ts`, `run-state.ts` |
| Outer-loop scheduler | `outer-loop.ts` |
| Local World | `world.ts` |
| Replay | `replay.ts`, `run-state.ts` |
| CLI | `cli-core.ts`, `cli.ts` |
