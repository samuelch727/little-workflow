# Code Of Conduct

## Our Standard

We expect project spaces to be professional, practical, and respectful. Good participation includes:

- Focusing criticism on ideas, code, documentation, and behavior.
- Giving enough context for others to understand and respond.
- Accepting maintainer decisions after concerns have been heard.
- Avoiding harassment, personal attacks, and discriminatory language.

## Unacceptable Behavior

Unacceptable behavior includes threats, harassment, sustained disruption, doxxing, sexualized attention, discriminatory remarks, and other conduct that makes participation unsafe or hostile.

## Enforcement

Maintainers may remove comments, close issues or pull requests, restrict participation, or ban contributors when behavior violates this code. Enforcement should be proportionate, documented when practical, and focused on protecting the project community.

## Reporting

Report conduct concerns to the repository maintainers using the least-public GitHub channel available. If no private maintainer channel is available, open a minimal public issue asking maintainers to establish private coordination and avoid including sensitive personal details in the public issue.
