`v0.1.0-beta` is the planned hardening phase for the Little Harness API.

Expected focus:

- clearer package exports
- stable Persistent Dir callback shapes
- improved trace browsing
- documented artifact retention
- first-party storage adapters
- tighter just-bash runtime configuration

The alpha guide remains the best place to understand the proposed developer experience.
