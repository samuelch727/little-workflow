The Little Harness integration for LittleDB (resolving the version a session
runs, tracing each turn, scores, and agent-made workflows behind review, all
through the private `createLittleDB()` client) is documented in one place:
[LittleDB with Little Harness](/docs/littledb/harness).

LittleDB is private source and not installable. Little Harness works without it,
including [Outcome Capture](/docs/harness/v0.1.0-alpha/build-agents/outcomes) to
local traces. See [LittleDB](/docs/littledb) for status.
