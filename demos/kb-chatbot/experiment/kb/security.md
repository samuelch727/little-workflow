# Security

Northwind Systems, IT security (fictional sample document).

## Passwords

- Minimum **14 characters**. Length beats complexity; a passphrase is fine.
- No scheduled rotation. Change a password only when there is a reason to.
- Never reuse a Northwind password on an external service.
- Passwords live in the company password manager, never in a document or a chat message.

## Multi-factor

- Multi-factor is mandatory on every Northwind account.
- A hardware key is issued at onboarding and is the preferred second factor. SMS codes are
  permitted only as a temporary fallback while a key is being replaced.

## Reporting a security problem

Email `security@northwind.example`. Device-loss and phishing incidents each have their own
procedure, maintained separately by IT security.
