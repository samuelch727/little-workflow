Only Little Harness and Little Workflow are installable. Status below was
checked on 2026-11-12.

| Product | Package | Status | Install |
| --- | --- | --- | --- |
| [Little Harness](/docs/harness) | `@little-stack/harness` | Published `0.2.0-alpha.3` on 12 November 2026, on `alpha` | `pnpm add @little-stack/harness@alpha ai@^7 zod @ai-sdk/<provider>` |
| [Little Workflow](/docs/workflow) | `@little-stack/workflow` | Published `0.2.0-alpha.3` on 12 November 2026, on `alpha` | `pnpm add @little-stack/workflow@alpha ai@^7 zod @ai-sdk/<provider>` |
| [LittleDB](/docs/littledb) | `@little-stack/littledb` | Private source, `0.1.0-alpha.2`, marked private. Not on npm, and no public repository | Not installable |
| [Workspaces, managed](/docs/how-they-fit#workspaces) | none: part of LittleDB's hosted service | Private, with LittleDB. Not on npm | Not installable |
| [Workspaces, self-hosted (Little Compute)](/docs/compute) | `@little-stack/compute` | Unpublished source; control plane frozen 2026-10-23. Not on npm, and not in the public `samuelch727/little-workflow` repository | Not installable |

Both published packages need Node.js 22 or newer and an AI SDK 7 provider
package. To create a project instead of installing by hand, use
[Setup](/docs/get-started/setup).

## Package names

The 3 November 2026 release is the first under the `@little-stack` npm scope.
Harness and Workflow now share version `0.2.0-alpha.3`; command names do not change.
LittleDB and Little Compute remain unpublished.

| Previous name | Current name | Command |
| --- | --- | --- |
| `little-harness` | `@little-stack/harness` | `little-harness` |
| `little-workflow` | `@little-stack/workflow` | `little` |
| (unpublished) | `@little-stack/compute` | `little-compute` |
| `@little-workflow/littledb` (private) | `@little-stack/littledb` (private) | none |

To move an existing project, replace the dependency names in `package.json`
and the module names in imports, including subpaths such as
`little-harness/connectors`, which becomes `@little-stack/harness/connectors`.
The packages already published under the old names stay installable.

## What UNRELEASED means

Sections labeled **UNRELEASED** depend on LittleDB or Little Compute, which
are not published on npm. Harness and Workflow features previously marked
that way on this site ship in `0.2.0-alpha.3`, including compiler, remote tools,
command correlation and workerd streaming. Earlier features shipped in alpha.2.

## The `v0.1.0-alpha` URL segment

Harness and Workflow pages live under `/docs/harness/v0.1.0-alpha/...` and
`/docs/workflow/v0.1.0-alpha/...`. That segment is a historical URL kept so old
links stay stable. It is not a package version: the published packages are
both `0.2.0-alpha.3`. There are no other version sections.
